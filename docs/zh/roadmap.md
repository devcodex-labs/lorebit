## 当前阶段：文档与边界冻结

当前目标是让未来使用者先理解 lorebit 的职责：RAG 主路径、证据与引用、知识生命周期，以及 database adapter 的边界。

## 后续阶段

1. **Core contracts**：冻结可验证的知识单元、revision、检索结果与 citation 契约。
2. **Reference path**：提供不绑定某个生产数据库内核的最小参考实现与测试。
3. **Adapter matrix**：按 capabilities 引入文档、向量、全文、图和 checkpoint adapter。
4. **Public SDK**：在真实可运行的安装、失败恢复和版本兼容路径就绪后，再发布 npm 包与接入文档。

没有发布日期或 API 名称的条目不构成发布承诺。每个阶段完成后，本站会把它从路线图转到可验证的用户文档和 reference。
