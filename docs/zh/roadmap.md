# 路线图

## 当前阶段：文档与边界冻结

当前目标是让未来使用者先理解并评审 lorebit 的职责：范围、资料准入、处理状态、带证据回答、知识生命周期，以及 adapter capability 的边界。U1–U7 与用户场景已经冻结为后续实现的产品事实源。

这不是接口发布时间表。路线图只说明会先验证哪些用户路径；在存在可运行入口、支持条件和失败恢复说明前，任何阶段都不应被理解为已经可接入。

## 后续阶段

1. **用户行为落地**：先让 U1–U5 的范围、资料、状态、证据和变化语义拥有可验证的参考路径。
2. **Reference path**：提供不绑定某个生产数据库内核的最小实现，并用三条用户场景验证结果。
3. **Adapter matrix**：按 U6 的 capabilities 引入文档、向量、全文、图和 checkpoint adapter；缺口必须有用户可见语义。
4. **Public SDK**：在真实可运行的安装、U7 恢复路径和版本兼容路径就绪后，再发布 npm 包与接入文档。

没有发布日期或 API 名称的条目不构成发布承诺。每个阶段完成后，本站会把它从路线图转到可验证的用户文档和 reference。

## 如何跟进变化

如果你的团队正在评估 lorebit，把当前工作流卡、能力缺口和三条验收场景保留下来。后续公开实现出现时，最有价值的更新会是“哪条用户路径已经可验证、适用于什么条件、失败时如何恢复”，而不是一串尚未说明边界的名称。
