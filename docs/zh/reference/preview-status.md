# 预览状态与公开契约

<span class="lorebit-label">参考 · 先区分已存在事实与目标设计</span>

## 当前已存在

- 本用户文档站与公开仓库。
- 已冻结的产品边界：通用、RAG-first、local-first、provider-neutral。
- 已冻结的存储边界：数据库与索引通过 adapter 接入，core 不实现数据库内核。

## 当前不存在

- `@devcodex/lorebit` npm 包。
- 可安装的 SDK、稳定 API、CLI 或配置文件。
- 生产级数据库 adapter、托管服务或数据库实现。

## 如何阅读本网站

概念页描述的是已确认的产品责任边界；它们不是对某个尚未发布函数或字段名的承诺。等公开实现出现后，文档会把每一项能力标注为可用版本、支持条件和失败恢复路径。

如果你正在选择技术路线，请把本站作为“应具备什么知识工作流”的依据，而不是立即接入指南。
