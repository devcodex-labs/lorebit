# 术语表

<span class="lorebit-label">参考 · 先理解用户概念，再接触实现符号</span>

本站的术语用于描述用户能看到的工作流和结果，不是当前 SDK 的类型、方法或配置字段。实现发布后，API reference 会补充相应符号，但不能取代这些业务含义。

| 术语 | 含义 | 不应误解为 |
|---|---|---|
| 知识工作流 | 从问题、资料到可引用回答，并能处理变化的一条路径 | 一次向量查询。 |
| 知识空间 | 为同类问题定义的资料、范围和回答合同边界 | 单个数据库或索引名称。 |
| 问题卡 | 对用户问题、拒答边界、证据和成功标准的简明说明 | 未发布的配置对象。 |
| 回答合同 | 结果必须包含什么、何时不能回答的规则 | 模型提示词的别名。 |
| 来源 | 可追溯的原始资料及其责任信息 | 任何复制来的文本。 |
| 修订 | 同一来源在不同时间的版本 | 一次无痕覆盖。 |
| 知识单元 | 可被定位、处理、更新和检索的内容单位 | 必然等于固定长度 chunk。 |
| 证据 | 实际支撑某项结论的资料片段与上下文 | 单纯的相似度分数。 |
| 引用 | 对来源、修订与位置的面向使用者表达 | 只放一个主页链接。 |
| 激活 | 满足合同、允许参与默认回答的状态 | 文件刚上传完成。 |
| 替代 | 新修订接管同一事实的关系 | 删除旧资料。 |
| 撤回 | 资料不再可信或不再允许作为默认依据 | 临时网络错误。 |
| adapter | 为一种存储或索引能力提供接入的边界 | lorebit 的数据库内核。 |
| capability | 某个 adapter 实际能声明和兑现的能力 | provider 的营销名称。 |
| 降级 | 条件不足时缩小结果、说明限制或转人工 | 静默换一种不等价行为。 |
| 当前事实 | 本站今天已存在、可验证的内容 | 未来设计目标。 |
| 0.x 目标合同 | 后续实现必须兑现的用户行为 | 已经可以安装的 SDK。 |
