# Preview status and public contract

<span class="lorebit-label">REFERENCE · HONEST STATUS BEFORE API SURFACE</span>

## What exists today

This repository contains the public documentation site and the architectural direction for lorebit. It does not yet publish `@devcodex/lorebit`, a stable SDK, a compatibility promise, or a built-in database implementation.

## What this means for users

| You can use these docs to | Do not infer that you can |
|---|---|
| Evaluate the product boundary | Install a released package |
| Plan sources, retrieval, and citations | Call preview names as production APIs |
| Decide where an adapter belongs | Assume a provider support matrix |
| Follow the implementation roadmap | Depend on compatibility guarantees |

## When this page will change

The status will move forward only when a concrete public entry point exists. At that time the documentation will add an install path, version policy, supported runtime information, adapter capabilities, and recovery guidance. Until then, the absence of an API is intentional and explicit.

Read [the roadmap](/en/roadmap) for the sequence of work.
